# REPORT — Лаб 3: конвертер валют (Spec Kit + Google Antigravity)

## 1. Источник данных и почему
Выбран официальный курс **Национального банка Молдовы (BNM)** в формате XML:
`https://www.bnm.md/en/official_exchange_rates?get_xml=1&date=DD.MM.YYYY`.

Почему BNM, а не сторонний API:
- это официальный курс страны, им пользуются банки и бухгалтерия;
- бесплатно, без регистрации и API-ключа, без лимитов запросов;
- есть курс на любую прошлую дату, это нужно для отката на последний опубликованный курс;
- в ответе есть номинал (`Nominal`), поэтому валюты вроде RUB за 100 единиц считаются точно.

Минусы: JSON-эндпоинта нет, только XML; курс публикуется около 13:00 по Кишинёву. Проверка показала, что BNM отдаёт курс и на субботу и воскресенье (копия пятничного), а для дат без курса (будущие даты) — пустой список.

## 3. Что агент собрал корректно с первой попытки
- Структура строго по plan.md: `bnm_client`, `parser`, `cache`, `rates_service`, `converter`, `validation`, `gui`, `__main__`; ядро не импортирует Tkinter.
- Разбор XML BNM с номиналом, пустой и битый ответ различаются (`NoRatesFoundError`, `InvalidDataError`).
- Конвертация через MDL на `Decimal`, кросс-курс в обе стороны, округление HALF_UP до 0,01, обратный курс до 4 знаков.
- Валидация: пусто, ноль, минус, буквы, запятая и точка как разделитель.
- Откат до 10 дней назад с явным сообщением: «No rates published for 25.10.2026; using official rates from 20.10.2026».
- Кэш JSON в `%APPDATA%`, переживает перезапуск; без сети — сообщение об ошибке и предложение «Use saved rates?», результат с подписью «cache from 20.10.2026».
- Сеть в отдельном потоке, окно не зависает.
- 27/27 задач отмечены в tasks.md, по коммиту на каждую группу задач; `python -m pytest`: 108 passed (на Python 3.14).

Проверка вживую (курс BNM на 20.10.2026): 100 EUR = 2010.53 MDL; 100 USD = 89.14 EUR; EUR→EUR = 100.00; «abc» и «-5» — ошибка без конвертации; «100,5» принимается.

## 4. Где агент ошибся и что пришлось исправлять
| Где | Что было не так | Как исправлено |
|---|---|---|
| `tests/test_rates_service.py` | Используется `Optional` без импорта. На Python 3.14 (ноутбук) это незаметно из-за отложенных аннотаций, а на Python 3.12, который требует конституция, сбор тестов падает с `NameError`. Агент проверял только на 3.14. | Повторным промптом агенту на ветке `tests` |
| `gui.py`, `_load_initial_rates` | Ошибка начальной загрузки курсов глушится (`except Exception: pass`). Без сети список валют содержит только 7 значений по умолчанию и не заполняется из кэша. | Не исправлялось, зафиксировано как расхождение с FR-014/FR-017 |
| `gui.py`, списки валют | При запуске валюты не выбраны; MDL в списке по умолчанию стоит последним, а после загрузки — по алфавиту в середине. | Не исправлялось, на работу не влияет |
| Формат результата | «100 EUR = 2010.53 MDL»: сумма без «.00» и без разделителя тысяч. Пример «100.00 EUR = 1 950.30 MDL» был в моём промпте, но Copilot не перенёс его в spec.md, поэтому агент его не видел. | Не исправлялось; это потеря при генерации спецификации, а не ошибка агента |
| Spec Kit (Copilot) | В конституции оставлена дата утверждения `TODO`; субагент не смог скачать страницу bnm.md при исследовании | Повторным промптом Copilot; в research.md отмечено, что поведение пустого ответа не проверено |
| Spec Kit, `/speckit-analyze` | 3 замечания (A1 точность обратного курса, A2 размытое «remains responsive», C1 нет задачи на показ ошибки разбора XML), затем 1 новое (MEDIUM «without noticeable delay») | Copilot исправил все по запросу, повторный analyze: 22/22 требований покрыты |
| Взаимодействие | Агент Antigravity просит подтверждение перед каждой командой терминала (git, python, pytest) | Подтверждал вручную пользователь |

Ручных правок кода не было: программа запускается в том виде, в каком её написал агент.

**Вывод.** Спецификация, написанная через Copilot (модель OpenAI), была выполнена агентом Antigravity (модель Google) почти полностью: все 27 задач, все основные сценарии работают с первой попытки, ручного кода не понадобилось. Расхождения появились там, где спецификация оставляла свободу (что делать при ошибке на старте, какая валюта выбрана по умолчанию), и там, где агент проверял результат только в своём окружении (Python 3.14 вместо 3.12). Отдельно видно, что часть требований теряется ещё на этапе генерации спецификации: пример формата результата из промпта не попал в spec.md, и агент сделал свой формат.
